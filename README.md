MIMII 工业机器异常声音检测实验

1. 项目简介
本项目为 MIMII 数据集异常检测任务。采用无监督学习中的自编码器（AutoEncoder）模型，在训练阶段仅输入正常机器的音频，学习其正常分布；在测试阶段，通过计算重构误差（MSE）来评估音频的异常程度。

2. 实验环境
- **OS**: Ubuntu (Linux)
- **Python**: 3.13
- **核心依赖**: PyTorch 2.15.0 (CPU版本), Librosa, Scikit-learn, Numpy
- **算力**: 本次测试基于 CPU 环境运行。

3. 数据集与特征提取
- **数据集**: MIMII Dataset (`pump` 泵机, `6_dB` 信噪比)。原始音频格式为 `.flac`。
- **特征处理**: 使用 `librosa` 提取 Log-Mel 频谱图（64 Mel 频带 × 32 时间帧）。针对音频长度不一的问题，进行了截断或补零处理，最终展平为 2048 维的一维向量。

4. 模型结构
采用经典的全连接自编码器（AutoEncoder）：
- **输入层**: 维度 2048
- **编码器 (Encoder)**: 2048 -> 256 (ReLU) -> 64 (ReLU) -> 8 (瓶颈层)
- **解码器 (Decoder)**: 8 -> 64 (ReLU) -> 256 (ReLU) -> 2048 (Sigmoid)
- **优化器**: Adam (lr=1e-3)
- **损失函数**: MSELoss

5. 实验结果
- **评价指标**: AUC-ROC
- **测试集 AUC**: **1.0000** 
*(注：本次实验为了保证在服务器运行时间内快速跑通流程，代码中限制随机抽取了部分样本进行训练和测试。)*

- **结果截图**: 见仓库内 `result.png`。
- **模型权重**: 见仓库内 `model.pkl`。

6. 运行指南
1. 确保环境已安装上述核心依赖。
2. 在 Jupyter Notebook 中打开代码文件。
